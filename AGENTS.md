# Repository instructions

- This repository is an Astro personal-portfolio project; `src/pages/index.astro` is the single-page entrypoint and `src/styles/global.css` owns the visual system.
- Treat `PRODUCT.md` and the README at `github.com/marianojhb/marianojhb` as the factual source of truth. Do not invent portfolio facts, project outcomes, or contact details.
- The intended product is a web portfolio showcasing selected work, experience, and contact information. Keep the work as the primary evidence and make contact/learning-more paths clear.
- Run `npm run dev` for local work and `npm run build` for production verification; there is no test suite yet.
- Impeccable is installed under `.opencode/`; use its design commands for frontend design work after restarting OpenCode.
